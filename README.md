# ✊✋✌️ Rock Paper Scissors Game

A light interactive browser application for the classic **Rock, Paper, Scissors** game built with **HTML5**, **CSS3**, and **Vanilla JavaScript**. The app features real-time score tracking, persistent storage via `localStorage`, and an auto-play simulator[cite: 12, 13].

---

## 📸 Features

* **Dynamic Result Calculation:** Automatically determines win, loss, or tie states upon selecting a move.
* **Auto Play Mode:** Runs automated matches against the computer every two seconds.
* **Persistent Score Keeping:** Retains game stats (wins, losses, ties) across browser sessions using `localStorage`.
* **Score Reset:** Dedicated control to clear saved records and restart the scoreboard[cite: 12, 13].
* **Dark Mode UI:** Styled with a dark theme and interactive custom emoji buttons[cite: 12, 14].

---

## 🛠️ Built With

* **HTML5** - Document layout and UI controls.
* **CSS3** - Dark theme styling and layout alignment using Flexbox[cite: 12, 14].
* **Vanilla JavaScript** - Game logic, conditional state handling, event listeners, and `localStorage` syncing[cite: 12, 13].
